# Backend

**Owner:** Backend developer.

## Technology
- Node.js
- Express.js
- SQLite (to be added)

## Setup

```bash
npm install
npm run dev
```

The starter server currently provides `GET /api/health`. Add the database schema, product routes, sales routes, validation and reporting endpoints here.

See `../docs/API.md` for the proposed API contract. Update it with your teammate before changing endpoint names or JSON fields.
